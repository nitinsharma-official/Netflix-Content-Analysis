# Netflix Content Analysis

## Project Overview
This project analyzes Netflix movies and TV shows using Python, Pandas, and NumPy. It explores content trends, ratings, release years, countries, genres, and other attributes.

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Dataset
The project uses the Netflix Titles dataset, which contains information about movies and TV shows available on Netflix.

## Project Files
- `Netflix-Content-Analysis.ipynb` — Notebook containing the data analysis.
- `netflix_titles.csv` — Original dataset.
- `netflix_cleaned.csv` — Cleaned dataset.

## Key Analysis
- Movies vs. TV Shows
- Content ratings and release years
- Country and genre analysis
- Movie duration and TV show seasons
- Missing-value handling and data cleaning

## Conclusion
This project demonstrates data cleaning, manipulation, filtering, and exploratory data analysis using Python, Pandas, and NumPy.
